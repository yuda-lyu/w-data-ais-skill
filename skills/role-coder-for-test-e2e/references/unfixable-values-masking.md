# 不可固定之值：分類、比對端遮蔽、差異分流與重產門檻

本篇是 SKILL.md §7.9（重產政策）與 §8.2（動態內容）的深入層。畫面上有些值每次執行或每次建置都不同，且無法以資料確定性固定；不處理好，標準圖就會因「非內容原因」被一再改寫，手冊與審圖跟著重來。**原則（業主裁示）：標準圖只因有效內容改變而重產；隨機或確認無法固定之值須先遮蔽——遮蔽後有效內容不變，就不重產，e2e 也照常通過。**

**順序**：§1 分類 → §2 盤點 → §3 遮蔽作法 → §4 差異分流 → §5 被藏起來的訊號 → §6 要問使用者時 → §7 失敗形狀 → §8 勾選。

## 1. 先分類：這個值由誰、在什麼時候寫入？

判別兩問：①兩次執行（或兩次建置）之間它會不會變？②假時鐘、mock、fixture、固定 seed 管得到它嗎？以答案決定處置，不以「它是不是時間戳」判斷——同樣是時間，執行期寫入者固定得住，建置時寫入者固定不住。

| 值的來源 | 例 | 能否固定 | 處置 |
|---|---|---|---|
| 執行期由程式取當下時間寫入 | 資料列之建立／變更／上傳時間、登入時間 | 能 | 程序級假時鐘（SKILL §8.2、[baseline-as-manual.md](baseline-as-manual.md) §5），不遮 |
| 後端或外部回傳之資料 | 統計圖、事件清單、日誌摘要 | 多半能 | mock 資料集、fixture log、固定 seed；仍漂移才覆蓋 |
| **建置／打包時寫入** | 離線產物標頭之產製時間、版本戳、資產雜湊 | **不能**：寫入發生在測試之外，假時鐘管不到 | 比對端覆蓋（§3） |
| **兩時間點之差** | 「處理完成，耗時 N 秒」 | **不能**：假時鐘保留 `Date.now()`，差值必然浮動 | 比對端覆蓋 |
| 即時量測 | CPU／記憶體使用率、在線人數 | 不能 | 比對端覆蓋，集中共用層一處（SKILL §8.2 第 3 條） |
| 隨機產生 | 亂數密碼、驗證連結之識別碼 | 不能 | 固定寬度黑條或覆蓋（[mail-roundtrip-verification.md](mail-roundtrip-verification.md) §5） |
| 非決定性渲染 | WebGL 地圖／三維場景、外部瓦片 | 不能 | 比對端「標準圖覆蓋＋DOM 貼回」（SKILL §8.2） |
| `<img>` 內 SVG 動畫 | 轉圈圖示 | 能 | 貼去動畫之靜態影格（SKILL §8.2） |

殷鑑：把建置時寫入之產製時間當成「版本內容變了」，沒歸入不可固定之值；每重建一次產物，含該標頭之圖就被逐張改寫。

## 2. 盤點：列出站點全集，不是撞到一個處理一個

1. **列軸**：畫面（流程 × 頁面）× 值（§1 各類）。
2. **成員自碼取得**，全範圍 grep（含打包管線與套件產物）：產製腳本寫入之時間戳（`builtAt`、`buildTime`、產製腳本內之 `new Date()`）、呈現「耗時／秒／ms」之字串、`performance.now()` 或 `Date.now()` 之差值、即時量測之 API、亂數產生之呼叫、`<canvas>` 與 WebGL 元件。
3. **每個值一列**，登錄專案映射表 C8：值｜出現在哪些流程與畫面｜覆蓋函式｜被覆蓋後以什麼語意斷言驗其值。
4. **對稱檢查**：同一畫面、同一性質之兄弟值逐一比對。覆蓋了耗時，就要問同畫面之產製時間、版本、計數是否同性質（殷鑑：同一頁之耗時早已覆蓋，旁邊標頭之產製時間沒比照，連續數次重建後才被點破）。
5. **產物**：盤點表（放映射表或規則帳本），表上不得有空白格。

## 3. 遮蔽作法：比對端覆蓋優先，填黑其次

| 作法 | 怎麼做 | 何時用 |
|---|---|---|
| 比對端覆蓋（優先） | 與截圖同一畫面狀態下量該值之矩形（頁面座標、外擴數 px、整數化並夾在圖內）；比對前以**標準圖同座標之內容**蓋上當次截圖再比對；**產製端原樣寫出**；矩形不在畫面內、或標準圖尚不存在（首次產製）時原樣回傳 | 讀者需要看到真實畫面者（版本、耗時、使用率、地圖）——標準圖即手冊用圖 |
| 填黑 | 產製端與比對端都把矩形填黑（SKILL §3 C8 `maskRegions`） | 讀者不需要看到該值，或值不宜公開 |
| 固定寬度黑條 | 以固定寬度之黑條取代字串（檢視器頁） | 隨機字串（密碼、識別碼） |

規則：

- **「手冊要看得到」與「比對要不要計入」是兩件事**。比對端覆蓋時，標準圖照樣保留真實畫面，手冊看得到版本行。以「這是使用者最需要看到的資訊」為由拒絕遮蔽、改為每次重產，是把兩件事混為一談（殷鑑：流程文件寫著「不遮罩該行——版本資訊正是使用者最需要看到的內容」，於是連續數次重建各重產十餘張）。
- **被覆蓋之值不等於不驗**：另以語意斷言驗其值，例如版本字樣等於產物 meta 之產製時間、耗時訊息之其餘文字逐字相符、使用率落在 0～100。覆蓋只把它移出像素比對。
- **集中一處**：同一個值在多個流程出現者，由共用層一個函式處理，各流程之比對端都呼叫它；各寫一份或漏一份都是缺口。
- **命中數自測**：上線前以兩張真圖跑一次，斷言每個目標命中 ≥ 1。選擇器寫錯會讓覆蓋永不生效而測試照綠（SKILL §8.2 第 1 條）。
- **範圍只限該值**（或其所在之一行）：覆蓋越大，被移出比對之有效內容越多；不擴大到整個區塊。

## 4. 差異分流：任何標準圖差異，先問是不是只在不可固定之值

**觸發**：mocha 比對失敗、`[baseline-headroom]` 告警、`--write-mode changed` 自動寫出了圖、或重建產物／升級套件後之重跑。

1. **量差異範圍**：逐像素比出差異之外接矩形，對應到 DOM 元素（落在哪段文字或哪個元件上）。
2. **只落在不可固定之值** → 不是內容改變，是遮蔽缺口：
   1. 補遮蔽（§3），同畫面同性質之值一併處理（§2 第 4 步）；
   2. 被自動寫出之圖以版控取回原標準圖——新舊兩張有效內容相同，保留新圖只是無故換掉已審過之真理；
   3. 以 `--write-mode changed` 重跑該等流程，**須零寫出**才算完成；
   4. 下游手冊若已帶入被改寫之圖，重跑其複製圖檔之步驟，並以雜湊核對手冊用圖與標準圖逐張相同；
   5. 流程文件、spec、規則帳本、代理記憶中寫著「X 之後重產 N 張」者一併改寫為遮蔽並留沿革，裁示登記於共用文件之裁決紀錄。
3. **不只落在不可固定之值** → 才進 [pixel-mismatch-diagnosis.md](pixel-mismatch-diagnosis.md) 查成因，或依 SKILL §7.9 取得授權後只產受影響者。
4. **產物**：差異分流紀錄，每張一列：差異矩形、對應元素、判定、處置。

**量測結果是成因的證據，不是改寫的背書**：量到「差異只在一段時間數字」時，結論是「該處未遮蔽」，不是「這次改寫是安全的」。

## 5. 被藏起來的訊號：容差、自動寫出、寫成慣例的重產

- **容差是給反鋸齒雜訊用的，不是給時間戳用的**。不可固定之值之差異常落在容差內（數十 px），比對照過、天天耗用餘裕，直到某次字寬一變才超出。同一區域每次重建或每次執行都出現非零差異，就是未遮蔽之訊號，不待超過容差才處理。
- **「有變更才改寫」會替你做決定**。超出容差即寫檔，判斷點在你看結果之前就過了；事後只核對「改寫安不安全」等於沒判斷。寫出之圖一律先走 §4 分流。
- **重複出現之重產紀錄是補丁訊號**。「重建後再重產 N 張，差異僅時間數字」出現第二次，就該根治，不是寫成慣例。寫在流程、規格或記憶裡的作法，同樣要能說出它在解決哪一格；說不出就是補丁，不照做。

## 6. 需要使用者決定時：選項要含成因層級之修法

- 能依本篇處理者（補遮蔽、取回原圖、零寫出重跑）直接處理，不問「這些圖要不要重產」「要不要保留」。
- 真要問時（例如某值屬「讀者要看到」而採覆蓋、或「不宜公開」而採填黑），選項要含成因層級之修法（補遮蔽），不只後果層級之選項（保留、還原、何時重產）。殷鑑：只問「改寫的圖要不要保留」「線上頁的圖何時接管後端重產」，遮蔽不在選項裡；業主反問「為何不是先問要不要制定遮蔽」。

## 7. 失敗形狀與對策（皆已實際發生）

| 形狀 | 錯在哪 | 對策 |
|---|---|---|
| 重建產物後，含產製時間之圖每次逐張改寫，手冊連帶重產 | §1：建置時寫入之值被當成內容改變 | 比對端覆蓋、取回原圖、零寫出重跑 |
| 同畫面之耗時已覆蓋，產製時間沒有 | §2 第 4 步：同類只做一半 | 盤點同畫面同性質之值 |
| 量到差異只在時間數字，拿來證明改寫安全 | §4：證據拿來背書 | 結論是「未遮蔽」 |
| 前幾次差異在容差內被忽略 | §5：容差把問題藏起來 | 同一區域反覆非零即處理 |
| `--write-mode changed` 自動寫出後才看 | §5：自動化藏起判斷點 | 寫出之圖先分流 |
| 流程文件寫「重建後全量重產」，理由是「版本是使用者要看的」，照做 | §3：手冊可見與比對計入混為一談；§5：照寫好之補丁做 | 改寫為覆蓋並留沿革，登記裁決 |
| 問使用者「要不要保留」「何時重產」 | §6：只給後果層級之選項 | 先處理成因；真要問時含遮蔽選項 |

## 8. 勾選

```
- [ ] 不可固定之值已依 §1 分類並登錄映射表（值／畫面／覆蓋函式／語意斷言），同畫面同性質之值已逐一比對
- [ ] 覆蓋集中於共用層一處：比對端呼叫、產製端原樣寫出；命中數自測通過；被覆蓋之值另有語意斷言
- [ ] 本輪任何標準圖差異（含 changed 模式自動寫出者）已逐張分流；只在不可固定之值者已補遮蔽、取回原圖、零寫出重跑
- [ ] 下游手冊用圖與標準圖雜湊逐張相同
- [ ] 流程／spec／規則帳本／記憶中「X 後重產 N 張」之寫法已改正並登記裁決
```
