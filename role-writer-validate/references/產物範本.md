# 產物範本（報告驗證）

每一層檢查都必須留下下列其中一種產物；產物放在 `./tmp/`（或使用者指定的專案 docs 目錄）。欄位可以增加，不可以減少；**表上不可以有空白格**——填不出來就是那一格還沒驗證，狀態欄寫「未驗」。

範例列中引用的檔案與行號取自實際安裝的 `w-dispatch-ai` 1.0.19（`node_modules/w-dispatch-ai/`）與 Codex CLI 0.149.0，2026-08-30 核對；其他版本行號可能不同。

## 0. 六問卡（每項檢查執行前填一張）

```
檢查名稱：
1. 檢查什麼：
2. 建置成本：
3. 誰執行：（確定性／AI／人／組合）
4. 實際證明了什麼：（只寫真的能證明的）
5. 產物：（檔名）
6. 工具：
```

## 6. 覆蓋聲明（回報末尾必附）

```
驗證覆蓋
- L0a 實體存在：已做，N 項——存在 a，修正 b，刪除 c（./tmp/validate-entities.md）
- L0b 需求對齊：已做，需求 N 條——已回應 a，刻意不回應 b（理由見矩陣），漏列 c 已補
- L1 主張溯源：已做（抽樣 §x／全量），主張 N 句——已證 a，改推測 b，刪除 c
- L2 實跑：已做，N 項——一致 a，差異 b 已處置
- L3 反向覆蓋：已做，盤點 N 項——已寫 a，刻意不寫 b，漏列 c 已補
- L4 專家確認：未做——待使用者逐條確認 ./tmp/validate-rules.md 的 N 條／已做，更正率 x%
- L5 持續一致：不適用（理由）
```

每層狀態只有：已做（附統計與產物路徑）／未做（附原因與待辦）／不適用（附理由）。
